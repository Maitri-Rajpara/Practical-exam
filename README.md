## PractiCal exam

## Maitri Rajpara

## Description :

- Memory Game
  Players: 2 (local multiplayer)
  Resumable: Yes (via localStorage)

- Requirements:
  4x4 or 6x6 shuffled card grid.
  Alternate turns between players.
  Matched pair = extra turn + point.
  Show current player and scores.
  Show end screen with winner.
  Save state: flipped cards, scores, turn.
  
- Stretch:
  Add a turn countdown timer (e.g., 60s) shown on screen.
  Restart and resume options.
  Focus: Game state, conditional logic, turn management, persistence.
